# MobilHafız — Gizlilik Politikası

Bu depo yalnızca [MobilHafız](https://play.google.com/store) Android
uygulamasının gizlilik politikasını barındırır. Google Play, veri
toplamayan uygulamalarda bile herkese açık bir gizlilik politikası adresi
şart koşuyor.

Yayınlanan sayfa: https://poisonwell69.github.io/mobilhafiz-gizlilik/

Kaynağı uygulama deposundaki `pazarlama/gizlilik-politikasi.html`
dosyasıdır; değişiklik orada yapılıp buraya kopyalanır.
